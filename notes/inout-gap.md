# IN/OUT との差分（作業記録）

対象は許諾済み `com.graff.inout` 1.0 (3)。根拠は公開解析 `06aefb3` の再構成・疑似コードと、`bin/IN-OUT` の型名と画面文言。元ソースではない。広告 SDK・識別子・秘密は写さない。

## 今回製品に入れたもの

| 動き | 区分 |
| --- | --- |
| 休憩選択 `0x1000e967c`、法定 (360,45)/(480,60)、customBreaks で勤務先の規則 | 再構成を実画面へ接続 |
| 編集の分数は終了−開始の 1440 正剰余。開始=終了は 0 のまま保存拒否 | 再構成 + 製品の既存拒否 |
| 文字と Intelligence 経由の「休憩N分」は手入力。書いていない行だけ規則 | 製品の安全判断 |
| 保存済みシフトは `breakFollowsRules == false` のまま。一括再計算なし | 製品の安全判断 |
| 週の表示移動は `addingWeeks`（×7日）。±1 はヘルプ文言の前後の週 | 再構成 + 文言。命令の ±1 は未回収 |
| 今日タブ、はじまり/終わりまでの表示、いま稼いだお給料 | 文言に画面がある。金額は `PayMath.timedAmount` の再実装 |
| 休憩の位置は未回収なので、無給分はシフトの末尾 | 再実装。途中の休憩時刻ではない |
| 交通費は今日の数字に足さない | 文言「お給料（交通費の前）」 |
| 日給と個別金額は秒で割らない | 再実装。元の日給式は未回収 |

## 文言と型で存在が分かり、まだ製品にないもの

カレンダーアプリとリマインダーへの保存、シフトパターン、曜日の繰り返し、シフト希望、遅刻連絡、移動時間、予定の重なり、勤務先の位置と地図、Google マップのリンク、ショップカード、給与明細との差、支払周期（日払・週払・月払）、時給の適用開始日、時間帯ごとの時給、丸め（1分/開始と終了）、年収の壁の追加と通知、勤務終了の確認通知、オンボーディング。広告を消す購入と Banner 系の型はある。広告は入れない。

## 未回収のまま

時給から金額を出す関数、`PayRounding` の適用、週オフセットを増減する命令、休憩へ渡す分数が編集入力と日付差のどちらで給与になるか、年収の壁の比較関数、休憩時間帯の置き方。
