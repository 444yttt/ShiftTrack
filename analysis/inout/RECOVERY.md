# IN/OUT からの回収範囲

対象は許諾済みの IN/OUT（`com.graff.inout`、表示名 IN/OUT、version 1.0 build 3、iOS 17+）の arm64 実機バイナリ。ShiftTrack のソースではない。Bundle ID、表示名、署名、プロビジョニングは転用していない。署名用プロファイルはアプリ内に無く、コード署名ディレクトリだけがあった。

## 手法

Linux 上では Mach-O を Python で読み、`__swift5_types` の相対ポインタから名義型 271 件（重複を除くと 232 件）と、型ディスクリプタが指すフィールド名を読んだ。`__text` は約 4.1MB で、定義済みシンボルはヘッダのみ。元の Swift ソースも、逆コンパイルで復元した疑似コードも得ていない。Capstone で命令列は出せるが、メソッドの実装には戻らない。

公開の別リポジトリは作っていない。この環境の GitHub 操作は読み取りに限られ、private の ShiftTrack を公開へ切り替えることもしていない。広告 ID と署名材料はこの文書にもリポジトリにも置いていない。

## 製品に使った事実

- 週の移動は「左右の矢印か横にスワイプで、前後の週に移る」と画面文言にある。フィールドも `__picked` / `__openDay` / `__slideEdge` と、シフト自身の日を分けている。しふとらっくでは、横スワイプは見ている月だけを変え、保存済み `WorkShift.date` は明示して日付を決めたときだけ変える。
- 時刻 UI の型名は `SlotTimePicker`、`SlotTimeWheel`、`MinuteOfDayRow`（フィールドは `label` と分）。実装は回収できないため、同じ役割を大きい時刻ボタン、専用シート、ホイール、±ボタンとして書き直した。元ソースのコピーではない。
- 休憩は分の整数のまま。日をまたぐ勤務（終了が開始より前）の計算は既存の `PayMath.workedMinutes` のまま。

## 載せなかったもの

広告関連の型（`BannerAdView`、`AdsController` など）と広告 SDK は入れてない。Intelligence、年収の壁、シフト表の取り込み、給料日集計、初回起動が空であることは IN/OUT 側の置換ではなく、しふとらっくの既存機能として残している。IN/OUT の週表示そのものへ画面構成を差し替えてはいない。
