# しふとらっく

勤務先ごとのシフトと、時給・交通費から出した収入の見込みを、端末の中だけで見る iOS アプリです。画面は黒地にライム（`#C8FF00`）です。

## 開き方

1. Xcode 16 以降で `ShiftTrack.xcodeproj` を開く。
2. スキーム **ShiftTrack** を選び、iPhone シミュレータ（iOS 17 以降）で実行する。
3. 署名チームは空のままでシミュレータに入れます。実機に入れるときだけ、Signing & Capabilities で自分のチームを選んでください。

GitHub Actions でもビルドを確認できます。`main` と `cursor/shifttrack-ios-app-0c12` への push と、それら向けの pull request で、iPhone シミュレータ向けの署名なしビルドが走ります（`.github/workflows/ios-build.yml`）。macOS 14 のランナーは 2026年11月に提供が終わったため、`macos-26` を使っています。TestFlight や App Store へのアップロードは含みません。

初回起動でサンプルが入っています。勤務先はカフェA・コンビニB・塾Cの3件で、今年のシフトが数週間分あります。11月はカレンダーとシフト一覧の見た目が揃うよう、日付を個別に入れています。

## 画面

下のタブは5つです。

- **カレンダー** … 月表示。勤務のある日は勤務先の色の点。日をタップするとその日のシフトを見て、追加・編集できます。上の勤務先フィルター（全て + 各勤務先）は、件数にかかわらず同じ幅で1行を埋めます。週の始まりは設定で月曜に切り替えられます（初期値は日曜）。
- **シフト** … これから / 過去。カードから編集、右上から追加。「シフト表から取り込む」は下の取り込みです。
- **収入** … 月と年を切り替えられます。見込みは「終わった勤務」と「これから入っている勤務」の合計です。今年を見ているときは、今日までの実績を年末まで引き伸ばした **今日時点の見込み**（ペース良好 / 遅れ）と、年収目標に対する **目標進捗**（バー、パーセント、残り金額）も出ます。目標額はカードの金額か、設定から変えられます。初期値は ¥1,000,000 です。
- **年収の壁** … 103 / 130 / 150 / 160 / 178 / 201万円。今年の見込み（終わった分 + 年末までのシフト）と比べます。カードをタップすると短い説明が開きます。税金の判定ではなく、目安です。
- **設定** … 勤務先の追加・編集（名前、色、時給、交通費、メモ）、年収目標、時給と交通費の初期値、週の始まり、交通費を収入に含めるか、サンプルへのリセット。

金額は `時給 × 実働分` を四捨五入し、設定で交通費を含めるときは勤務のたびにその勤務先の交通費を足します。日をまたぐ勤務は終了時刻が開始以下のときに翌日扱いです。時給を変えると、見込みは保存済みのシフトから計算し直します。

## シフト表から取り込む

シフトタブの **シフト表から取り込む** から、次のどれかを入れます。

- 写真ライブラリの画像
- カメラで撮ったシフト表（カメラを使うときだけ許可を求めます）
- テキストの貼り付け、またはその場での入力

読み取ったあと、確認画面で勤務先・日付・開始・終了・休憩を直せます。チェックを外した行は保存しません。同じ勤務先・日付・開始・終了が既にある行は飛ばします。知らない勤務先名は、設定の初期時給・交通費と次の色で新しく作ります。**保存するまでシフトは増えません。**

文字の例:

```
11/7 カフェA 10:00-15:00
11月8日 コンビニB 18:00-23:00 休憩 30分
2026-11-10 塾C 16:00-19:00
```

画像は Vision の文字認識（日本語と英語、端末内）にかけます。日付と時刻の並びが読み取れれば、上と同じ規則で候補にします。

### Apple Intelligence と Siri

iOS 26 で Apple Intelligence が使える端末では、読み取った文字を **端末内の Foundation Models** でシフト（勤務先・日付・開始・終了・休憩）に整理してから、同じ確認画面に出します。モデルが使えない、オフ、未対応、失敗のときは、日付と時刻のパターン抽出に戻ります。確認画面の文面で、どちらで作ったかを知らせます。

Siri やショートカットからは、アプリ名を含めて話しかけます。

- 「しふとらっくでシフト表を取り込む」
- 「しふとらっくにシフト表を読み込んで」

ショートカット App のアクション **シフト表の画像を取り込む** に画像を渡すと、同じ確認画面が開きます。

App Intents 自体は iOS 17 以降でも登録されます。Apple Intelligence の整理は、対応 OS・対応端末で Apple Intelligence がオンのときだけです。それ以外は手入力とテキスト貼り付け、およびパターン抽出が使えます。

## プライバシー

勤務先、シフト、設定は SwiftData で端末内に保存します。シフト表の画像も文字も、サーバーへは送りません。Apple Intelligence を使う場合も端末内モデルだけで、Private Cloud Compute には出しません。通信が必要な処理はありません。

カメラの使用目的は Info.plist の `NSCameraUsageDescription` に書いてあります。写真はシステムのピッカー経由なので、フォトライブラリ全体への許可は求めていません。追加の entitlements は不要です。追跡もしません（`PrivacyInfo.xcprivacy`）。

## 補足

ローカルに Xcode がない環境ではコンパイルできません。その確認は GitHub Actions の iPhone シミュレータ向けビルドで行います。Apple Intelligence のパスは、Foundation Models がある SDK（Xcode 26 以降）でだけコンパイルに含まれ、それより前の SDK ではパターン抽出だけが残ります。
