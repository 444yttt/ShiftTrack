# しふとらっく

勤務先ごとのシフトと、時給・交通費から出した収入の見込みを、端末の中だけで見る iOS アプリです。紙色の背景に白いカード、アクセントはライム（塗りだけに使う）です。デザインの決まりは `docs/design/redesign.md` にあります。

## 開き方

1. Xcode 16 以降で `ShiftTrack.xcodeproj` を開く。
2. スキーム **ShiftTrack** を選び、iPhone シミュレータ（iOS 17 以降）で実行する。
3. 署名チームは空のままでシミュレータに入れます。実機に入れるときだけ、Signing & Capabilities で自分のチームを選んでください。

GitHub Actions でもビルドを確認できます。`main` と `cursor/shifttrack-ios-app-0c12` への push と、それら向けの pull request で、iPhone シミュレータ向けの署名なしビルドが走ります（`.github/workflows/ios-build.yml`）。macOS 14 のランナーは 2026年11月に提供が終わったため、`macos-26` を使っています。TestFlight や App Store へのアップロードは含みません。

初回起動では勤務先もシフトも空です。ホームか勤務先タブから勤務先を1件登録すると、シフトを入れられます。目標と時給の初期値だけ入ります。

## 画面

タブは左から ホーム / カレンダー / 給料 / 勤務先 / 設定 です。画面ごとの構成は `docs/design/redesign.md` の「Navigation map」にあります。

- **ホーム** … 時間帯で変わる景色（SwiftUI の Canvas で描いたオリジナル）と、点の文字（Doto）の時計。週の日付、その日のシフト、勤務中は「いままでの稼ぎ」が1秒ごとに増えます（時給・割増から計算し、休憩は勤務時間全体にならして引きます）。いま働いている勤務先の 地図 / 電話 / メッセージ（住所や電話番号が無いときは押せず、理由を表示）、今日のやること、今月のまとめ。
- **カレンダー** … 月の表示、選んだ日のシフトと希望、シフトパターン（選んだ日・まとめて選んだ日に置く、取り消し）、曜日でまとめて入れる、シフト希望、シフト表の取り込み。
- **給料** … 月ごと / 年ごと。給料日のある月で数えた見込み、目標と進み具合、勤務先ごとの割合、給料日ごとの見込み、月の内訳、年収の壁、年収の目安。
- **勤務先** … 勤務先ごとのカード（時給・交通費・締め日と給料日・地図 / 電話 / メッセージ・シフトパターン）。追加は3ステップの登録、編集は1画面（締め日と給料日は1か所だけ）。
- **設定** … 通知、連絡メッセージのひな形、カレンダーとリマインダー、シフトの重なり、カレンダーの表示、給料の計算、新しい勤務先の初期値、位置情報、Siri、フォントのライセンス。

時給は実働分で計算します。深夜・休日の割増は、金額を決めた勤務先はその時給、割合を決めた勤務先は時給にその割合を足します。残業は決まった時間を超えた分に金額か割合を足します。日給の勤務先は休憩を引きません。交通費を含める設定のときは、シフトのたびに勤務先の交通費を足します。給料の個別設定があるシフトは、その金額を使います。

## シフトパターン（まとめて置く型）

- **カレンダー / 一覧** の「シフトパターン」で、時間・休憩・やることを登録します。名前の横の鉛筆、または「一覧」から **編集・削除** ができます。
- 休憩はパターンごとに決められます。**分数** / **勤務先の決まり**（シフトを直すと休憩も追従）/ **専用の決まり**（このパターンだけの「◯分を超えたら◯分」）。日給の勤務先は休憩を入れません。
- タップすると、見ている日（または選んだ日）に置きます。直後なら「取り消す」で戻せます。「シフトを追加」の画面からも1タップで置けます。
- 「曜日でまとめて入れる」（曜日の型）にも同じ休憩の選択があります。
- 削除しても、すでに置いたシフトは残ります。保存済みのパターンは、休憩の項目が増えても今までどおり休憩なしで置かれます（追加項目はすべて既定値つきで、既存データはそのまま開けます）。

## 入力まわり

- 保存したシフトは、編集画面の「このシフトをコピー」から、翌日・来週の同じ曜日へ1タップでコピーできます（同じ勤務先・時刻がある日は足しません）。
- 勤務先がまだ無いときは、ホームから勤務先の登録に進めます。
- 各タブの「？」は、その画面の見方をシートで開きます。

## 読みやすさ

- 文字は WCAG AA（4.5:1）以上、スイッチや入力欄の枠は 3:1 以上の組み合わせだけを使います。ライムは塗りの色で、文字には使いません。表は `ShiftTrackTests/ThemeContrastTests.swift` と `docs/design/redesign.md` にあります。
- 文字は Dynamic Type に合わせて大きくなります（最大 AX3。タブバーは xxxLarge まで、長押しで拡大表示）。押せる所は 44pt 以上です。アニメーションは「視差効果を減らす」で止まります。
- 時計・シフトの時刻・金額の点の文字は Google Fonts の Doto（SIL Open Font License 1.1、`ShiftTrack/Fonts/OFL.txt`）です。VoiceOver には「14時5分」のように読み上げる文を渡しています。

## シフト表から取り込む

カレンダーの「ほかの追加方法」→ **シフト表から取り込む** から、次のどれかを入れます。

- 写真ライブラリの画像
- カメラで撮ったシフト表（カメラを使うときだけ許可を求めます）
- テキストの貼り付け、またはその場での入力

読み取ったあと、確認画面で勤務先・日付・開始・終了・休憩を直せます。チェックを外した行は保存しません。同じ勤務先・日付・開始・終了が既にある行は飛ばします。知らない勤務先名は、設定の初期時給・交通費と次の色で新しく作ります。保存するとカレンダーのその日に戻ります。カレンダーで勤務先を選んでいるとき、名前や日付の無い行はその勤務先と、開いている日として読みます。

文字の例:

```
11/7 カフェA 10:00-15:00
11月8日 コンビニB 18:00-23:00 休憩 30分
2026-11-10 塾C 16:00-19:00
```

画像は Vision の文字認識（日本語と英語、端末内）にかけます。日付と時刻の並びが読み取れれば、上と同じ規則で候補にします。

### Apple Intelligence と Siri

iOS 26 で Apple Intelligence が使える端末では、読み取った文字を **端末内の Foundation Models** でシフト（勤務先・日付・開始・終了・休憩）に整理してから、同じ確認画面に出します。モデルが使えない、オフ、未対応、失敗のときは、日付と時刻のパターン抽出に戻ります。確認画面の文面で、どちらで作ったかを知らせます。

Siri やショートカットからは、アプリ名を含めて話しかけます。

- 「しふとらっくでシフト表を取り込む」
- 「しふとらっくにシフト表を読み込んで」

ショートカット App のアクション **シフト表の画像を取り込む**（iOS 18 以降）に画像を渡すと、同じ確認画面が開きます。アプリ内の写真・カメラ・テキスト貼り付けは iOS 17 でも使えます。

App Intents 自体は iOS 17 以降でも登録されます。Apple Intelligence の整理は、対応 OS・対応端末で Apple Intelligence がオンのときだけです。それ以外は手入力とテキスト貼り付け、およびパターン抽出が使えます。

## プライバシー

勤務先、シフト、設定は SwiftData で端末内に保存します。シフト表の画像も文字も、サーバーへは送りません。Apple Intelligence を使う場合も端末内モデルだけで、Private Cloud Compute には出しません。通信が必要な処理はありません。

カメラの使用目的は Info.plist の `NSCameraUsageDescription` に書いてあります。写真はシステムのピッカー経由なので、フォトライブラリ全体への許可は求めていません。追加の entitlements は不要です。追跡もしません（`PrivacyInfo.xcprivacy`）。

## TestFlight

`.github/workflows/testflight.yml` は、手動実行と `main` のアプリ本体・プロジェクトへの push で、Archive、IPA の書き出し、`xcrun altool --upload-app` まで進めます。Bundle ID は `app.shifttrack.ios`、表示名は「しふとらっく」です。Team ID はプロジェクトに書かず、実行時の `DEVELOPMENT_TEAM` で渡します。ビルド番号は Actions の run number です。

必要な Actions secrets は `ASC_KEY_ID`、`ASC_ISSUER_ID`、`ASC_PRIVATE_KEY`、`APPLE_TEAM_ID` です。値はこのリポジトリにありません。未登録のあいだはアップロードを実行しません。

## 補足

ローカルに Xcode がない環境ではコンパイルできません。その確認は GitHub Actions の iPhone シミュレータ向けビルドで行います。Apple Intelligence のパスは、Foundation Models がある SDK（Xcode 26 以降）でだけコンパイルに含まれ、それより前の SDK ではパターン抽出だけが残ります。
